# Notice

MudSort is a port of **mudsort** by mudzereli
(<https://github.com/mudzereli/mudsort>), the Decal inventory sorter for
Asheron's Call, to a WebAssembly plugin for openAC-rust. It is ported with
mudzereli's permission; mudzereli releases mudsort under the MIT licence.
The port keeps mudsort's sort keys and their codes, its sort-string format,
its string order and its sort, so a mudsort sort string sorts the same way
here.

mudsort's string order is Dave Koelle's Alphanum algorithm
(<http://www.DaveKoelle.com>), in the C# version by Jonathan Ruckwood as
adapted by Dominik Hurnaus, which mudsort ships as `AlphanumComparator.cs`.

The tests compare against files generated by running mudsort's own
`SortFlag.cs`, `Enums.cs` and `AlphanumComparator.cs` (`tools/golden`); those
files are not part of this repository.

The plugin is built on the openAC plugin SDK
(<https://github.com/eriknihlen/openac-rust>, MIT).
